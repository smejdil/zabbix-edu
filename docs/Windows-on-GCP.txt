Windows Server 2019 pro školení Zabbix
=====================================

1. Příprava stanice, ze které poběží Ansible:
   - gcloud CLI s přístupem k projektu datascript-zabbix-edu a IAP TCP tunneling
   - ansible-playbook, kolekce ansible.windows a community.windows, pywinrm

   ansible-galaxy collection install ansible.windows community.windows
   # pywinrm nainstalujte do stejného Python prostředí jako Ansible

2. Vytvoření VM z kořenového adresáře repozitáře:

   ./scripts/create_windows_vm_machine.sh 01

   Skript používá rodinu windows-2019, nikoli výběr image podle textového filtru.
   PowerShell bootstrap je předán jako sysprep-specialize-script-ps1, takže se
   spustí při prvním bootu. Vypne IE Enhanced Security Configuration a připraví
   WinRM přes HTTPS. Skript jednou vytvoří GCP firewall pravidlo pro port 5986,
   omezené na IAP rozsah 35.235.240.0/20 a tag zabbix-edu-winrm.

3. Až Windows dokončí první boot, vytvořte administrátorský účet a heslo:

   gcloud compute reset-windows-password winsrv01 \
     --project=datascript-zabbix-edu --zone=europe-west4-a --user=ansible

   Heslo si poznamenejte. Skript pro Ansible se na něj zeptá a neuloží jej do
   souboru v repozitáři. Účet lze použít také pro RDP. RDP soubor lze stáhnout
   z Compute Engine konzole a otevřít přes mstsc nebo Remminu.

4. Instalace IIS a Zabbix Agenta 2 přes Ansible:

   ./scripts/install_windows_agent2.sh 01

   Skript otevře lokální IAP tunel na WinRM HTTPS (localhost:15986), počká na
   dostupnost Windows a spustí zabbix/ansible/install-windows-agent2.yml.
   Pokud jste v kroku 3 zvolili jiné jméno, nastavte WINDOWS_USER=jmeno.
   Pro více VM spusťte příkaz zvlášť pro každé číslo.

   Playbook instaluje IIS včetně IIS Management Scripts and Tools, stáhne
   aktuální Zabbix Agent 2 ze stabilní větve 7.0, nastaví pasivní servery
   enceladus.pfsense.cz a zbx01-zbx12.pfsense.cz, povolí TCP 10050 ve Windows
   Firewallu a zajistí spuštěnou službu. MSI se neinstaluje ručně přes RDP.
   Pravidlo GCP firewallu pro tag zabbix-agent musí umožnit TCP 10050 z vašich
   Zabbix serverů; toto pravidlo projekt spravuje odděleně.

5. Kontrola přímo ve Windows, případně přes RDP:

   Get-Service 'Zabbix Agent 2'
   Get-WindowsFeature Web-Server,Web-Scripting-Tools
   Get-Content -Path 'C:\Program Files\Zabbix Agent 2\zabbix_agent2.log' -Wait -Tail 10

   IIS otestujte na http://<externi-IP-VM>/ .

Firefox, Total Commander, PuTTY a WinSCP z původních poznámek jsou volitelné
nástroje pro práci přes RDP. Pro instalaci Agenta 2 ani IIS nejsou potřeba;
instalujte je podle potřeby z jejich oficiálních stránek.
